# ケラバの共有データ

公開アプリの「保存」「開く」から、ケラバの入力をGitHubへ直接保存・読み出しします。

アプリ: https://miyagoshigotono-lgtm.github.io/bolt-effective-length/#keraba

- 保存: アプリの「GitHub接続」で接続した後、「保存」で名前を確認します。
- 読み出し: 「開く」で一覧から選びます。公開データの読み出しには接続キーは不要です。
- 保存場所: `main` ブランチの `projects/*.json`。通常・瓦の表示中の入力だけを保存します。
- 既存のJSON: アプリの「開く → 以前のJSONを取り込む」から開き、「保存」で登録します。
- 同時更新: 読み出した版と違う場合は保存を止めます。開き直すか、別の名前で保存してください。

利用者の方針により、このリポジトリは公開です。保存名・入力データと変更履歴は公開されます。接続キーや認証情報は登録しません。

接続キーは、この保存先だけを選んだ fine-grained personal access token（Contents: Read and write）を使います。アプリの接続画面に発行リンクと手順があります。接続はタブを閉じるまで有効です。
