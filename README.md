# ケラバ旧保存データ

現在のケラバの保存先は、接続操作なしで使える専用クラウドへ変更しました。

[アプリを開く](https://miyagoshigotono-lgtm.github.io/bolt-effective-length/#keraba)

アプリの「保存」「開く」「リセット」を使います。パスワード・GitHub接続キー・ログイン操作は不要です。保存一覧はPC・ブラウザごとに分かれます。

このリポジトリは、以前保存したJSONの保管用として残します。新しいアプリからここへ保存することはありません。既存JSONを使う場合は、アプリの「開く → 以前のJSONを取り込む」で開き、「保存」で新しいクラウドへ登録してください。既存のファイルや履歴は削除しません。
